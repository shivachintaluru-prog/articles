The fastest way to give feedback:

1. Read the live version (link above).
2. Open an [issue](https://github.com/shivachintaluru-prog/articles/issues/new) with the article slug in the title — e.g. `the-curious-case-of-cli-ux: para 7 reads as preachy`.
3. Or DM me on LinkedIn.

## Adding a new article

```
articles/
├── index.html                       # landing page (manually update with the new entry)
├── README.md
└── <slug>/
    └── index.html                   # the article itself
```

The site is served via GitHub Pages (`main` branch, root). Push to `main` → live in ~60 seconds.
