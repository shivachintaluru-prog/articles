The curious case of CLI UX

I learned to write on a slate.

A small black tablet. A chalk pencil. A wet rag to wipe it clean. Telugu first, then English. The alphabet practised one letter at a time on a surface that erased every mistake by lunchtime. Millions of South Asian kids learn to read and write this way. I was one of them.

I spent the next fifteen years learning to ship the opposite of a slate.

Buttons. Dropdowns. Tooltips. Progress bars. The disabled state on the Save button. Every UX component I’ve shipped exists to enforce a script: buttons tell the user what they’re allowed to ask for, dropdowns tell them when. Modals interrupt. Tooltips explain. Sidebars file. Colour everywhere. Every component a tiny decision the user no longer has to make for themselves.

That was the contract. The interface negotiates with the user on behalf of the system. The job of UX is to reduce the moments where the user has to think.

Six days ago I opened Claude Code.

The ugliest interface I’ve used in years is the one I can’t stop opening. No colours. No icons. No menus. No reassuring blue button telling me what to click next. Just a blinking cursor and a black box.

I’ve been in there 6–7 days a week since. Building automations. Building ideas. Mostly just learning. For the first time in my PM career, I’m coding.

Six days is too short to be sure of any of this. I’m writing it down anyway because the shift has been violent enough that I don’t want to forget what it felt like before.

Chat had been training me to wait.

When I’m in ChatGPT, the loop is: send a message, get an answer almost instantly, respond, repeat. Logan Kilpatrick made the point on Lenny’s podcast that the chat interface trains the ask. If the box says “type and wait,” I only ever typed things short enough to wait for.

The CLI flips that. I write intent. I hit return. I walk away. Sometimes for two minutes, sometimes twenty. When I come back, there’s a working thing.

The real variable isn’t the terminal. It’s run length. Once a model can work for twenty minutes on one instruction, the synchronous chat loop is the wrong shape for it, whether the wrapper is a terminal, a Slack bot, or a web app. The CLI just happened to be the first place I felt it, because it ships with no affordances pulling me back into the supervising habit.

Type intent. Get a working thing I couldn’t have shipped before. Type the next. Get another. By the third one in a session, my brain has wired the loop. By day 4, I was checking the terminal in airport queues. That high doesn’t come from a sidebar watching me type. It only comes from walking away and coming back to something I couldn’t have built.

The pent up energy that always stopped PMs wasn’t fear. At least, mine wasn’t. It was the interface.

I’ve opened VS Code, read three lines of someone else’s code, felt the weight of “I should know what these brackets mean by now,” and closed the tab. More times than I want to say. Cursor helped. Replit helped. The chat sidebar helped. None of them removed the part where the IDE was still teaching me to write code in the margins, with autocomplete and red squigglies that all said the same thing: you’re not really one of the people this interface is for.

Alexander Embiricos has said memorising syntax matters less now and saying what you want matters more. The CLI is the first surface that bets fully on that shift. It doesn’t teach me syntax. It barely shows me any. I describe. It builds. I read. I keep or discard.

I described a Slack bot. It built it. I described an automation that scrapes a feed and posts to a channel. It built it. Neither is interesting. Both are things I would never have shipped on my own before this week.

Every UX heuristic I was taught has a regime. They’re not laws. They’re rules for a contract: the contract where the interface has to negotiate on behalf of a system that can’t read the user’s intent. The CLI is a regime where that contract has shifted. The model reads intent. The negotiation isn’t needed. And every component I was taught to add is now teaching me to add things I no longer need to add.

Who knew colours and UX components are this much distracting.

I learned to write on a slate. I spent fifteen years learning to ship apps with colour and buttons. Six days in Claude Code and I’m back on a slate. Different chalk.
